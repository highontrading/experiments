# Praja Video 3: Ek jagruk nagrik ka safar

The explainer video for "Praja Video 3: Simple Narration Script (Praja style)". It runs
25 slides in 5:10. The voice-over is generated by ElevenLabs, and the look is the
"American File" collage: a slate-blue board, torn cream paper, ransom-note letters,
masking tape, yellow tape, a yellow marker and halftone ink.

| File | What it is |
| --- | --- |
| `out/praja_video_3.mp4` | the video: 1920x1080, 30 fps, 5:10, H.264 + AAC, -14 LUFS |
| `script.py` | the VO script from the PDF. Each line holds the on-screen caption (Roman, word for word from the PDF) and the Devanagari the voice reads |
| `vo.py` | ElevenLabs TTS: one take per slide (7+8 and 22+23 as one take), with character timings |
| `sfx.py` | ElevenLabs sound effects (paper, tape, stamp, typewriter, marker, UI) and the music bed |
| `timeline.py` | the timing source: slide times, VO placement, word cues, captions |
| `stage.html`, `stage.js` | the whole video as `renderAt(t)`: every scene, transition and caption |
| `render.js` | renders frames with headless Chromium and streams them into the encoder |
| `sound.py` | the mix: VO (5% faster, EQ, compression), music ducked under the voice, every SFX on its frame |
| `make.sh` | the whole build |

## How it is timed

Every on-screen beat is tied to a spoken word. In `timeline.py`, `CUES` names a word
for each slide (for example `"vote": "वोट"`). ElevenLabs returns timings for each
character, so the vote card drops exactly when the narrator says "vote". The SFX for
that drop is scheduled by the stage itself and lands on the same frame.

## Choices made from the PDF's notes

- Voice: "Amrut Deshmukh, Booklet Guy (Hindi)" from the account's voice library, on
  `eleven_v4`, with a calm and clear delivery. LISTEN / INFORM / RESPOND / FACILITATE
  are said in English, as the PDF asks.
- Slide 21 (property tax) is placed after slide 19 (single window), as the PDF suggests.
  Its VO is still marked "confirm with Praja" there.
- Slides 7+8 and 22+23 are voiced as one sentence each, and only the slide changes.
- On-screen fixes: "How do citizens", "Building", "Aadhaar", "Open Space",
  "centralised complaint system", and "BMC" on the chatbot.
- The Praja mark is a text wordmark. The real logo can go in `BUILD[1]` and `buildOutro`
  in `stage.js`.

## Build

You need Node with `playwright` (Chromium), Python 3 with `numpy`, `scipy` and
`requests`, `ffmpeg`, and `ELEVENLABS_API_KEY` set in the environment.

```bash
./make.sh stills   # one still per slide -> build/contact.png
./make.sh          # full build -> out/praja_video_3.mp4 (about 20 min on 4 cores)
./make.sh encode   # re-mix and re-encode only
```

ElevenLabs output is cached in `build/`, so a rebuild spends no credits. To re-voice
one slide, delete its `build/vo/take_XX.*` and run `python3 vo.py` again.
