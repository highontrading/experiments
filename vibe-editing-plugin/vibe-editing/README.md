# Vibe Editing (Claude Code plugin)

Edit videos by telling Claude what you want. Vibe Editing cuts dead space, pauses, retakes and
filler words, adds captions in your style, writes hooks, adds punch-in zooms, kinetic type,
titles, lower thirds, B-roll, sound design and a colour look. Its **style scraper** copies the
editing style of any reference reel or photo. Before anything renders you review and change the
edit on the **edit board** in your browser.

Three skills:
- `vibe-edit`: the whole workflow: brief → analyze → style → plan → edit board → render
- `vibe-style`: scrape a style from reference videos/photos into your style library
- `vibe-setup`: install and check Python, ffmpeg and Whisper (Mac and Windows)

**Start here: [GUIDE.md](GUIDE.md)** (install, first edit, every feature, lecture plan).

Needs: Claude Code (desktop app or terminal), Python 3.9+, ffmpeg 5+. Runs fully on your
laptop; footage never leaves your computer except the text you share with Claude.
