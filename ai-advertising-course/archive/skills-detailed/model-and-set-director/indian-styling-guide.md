# Indian styling guide (reference for model-and-set-director)

## Skin tones: describe, don't default
AI image models often lighten Indian skin or smooth it into plastic. Always say the tone and
the texture, and add "no skin lightening" in Avoid.

| Say this | Not this |
|---|---|
| deep brown skin with cool undertones, natural texture | dark |
| warm medium-brown skin, golden undertone, visible pores | wheatish / dusky |
| light olive-brown skin, warm undertone | fair |
| natural skin texture, soft sheen on cheekbones | flawless, porcelain |

## Outfits: name them correctly
| Garment | Key words for the prompt |
|---|---|
| Saree | drape style (Nivi / Bengali / Maharashtrian nauvari), pallu over left shoulder, pleats, blouse style, fabric (Banarasi silk, Kanjeevaram silk, handloom cotton, chiffon, organza) |
| Lehenga | flared skirt, choli, dupatta draped, embroidery type (zardozi, gota patti, mirror work) |
| Kurta set | straight / A-line / anarkali, churidar or palazzo, dupatta |
| Sherwani / bandhgala | knee-length, mandarin collar, buttons, stole, juttis |
| Men's kurta | cotton/linen, nehru jacket optional, mojaris |
| Fabrics | matte cotton, crisp linen, raw silk slub, heavy silk with zari sheen, flowing georgette |

Jewellery: jhumkas, kundan, temple jewellery (South), polki, nath, maang tikka, bangles (glass/gold),
kada. Keep it to what fits the occasion.

## Occasions & settings
| Occasion | Set ideas | Light |
|---|---|---|
| Diwali | diyas, rangoli, marigold torans, fairy lights | warm low diya light + bokeh |
| Wedding / haldi / mehendi | marigold, yellow drapes, mandap, brass urli with flowers | bright warm daylight / golden |
| Holi | colour powder clouds, white kurtas | hard bright sun |
| Eid | lanterns, arches, sheer curtains | soft evening light |
| Onam / Pongal | kasavu sarees, pookalam, banana leaves | soft morning sun |
| Everyday urban | Mumbai balcony, Bengaluru café, Delhi metro, auto-rickshaw | natural daylight |

## Respect rules
- Use correct names for regional dress; don't mix costume elements randomly.
- Religious symbols only when relevant and shown respectfully.
- Show real Indian diversity: regions, body types, ages, skin tones.
- Avoid "exotic" or poverty-tourism framing.
