# Shot List

**How to fill:** One row per shot you need to generate. Use it in Flow so nothing is missed and every
shot matches. Name every file with the naming rule:
`BRAND_CAMPAIGN_CONCEPT_HOOK_FORMAT_RATIO_v01` (e.g. `KESAR_DIWALI_GLOW_H03_FILM_9x16_v01`).
Add `_S01`, `_S02` for shot numbers inside a film.

**Shot type codes:** ECU extreme close-up · CU close-up · MCU medium close-up · MS medium · WS wide · TOP top-down · POV
**Camera move codes:** STATIC · PUSH push-in · PULL pull-out · ORBIT · DOLLY L/R · TILT · CRANE · HANDHELD · WHIP
