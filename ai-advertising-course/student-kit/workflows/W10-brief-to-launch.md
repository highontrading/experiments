# W10: Brief → Launch (Master Workflow)

**Goal:** Run one full campaign through the 6 steps, **Brief → Concept → Visuals → Motion → Edit → Launch**,
using all the other workflows. This is the capstone workflow.
**Time:** 2–5 days for one person (one focused day for a small campaign) · **Used in:** Lecture 11

**Tools + models:** Claude / ChatGPT / Gemini with skills · Google Flow (Nano Banana 1.1, Google Omni Flash 1.2)
· ChatGPT (GPT Image 2.6) · ElevenLabs · Suno · Claude with `vibe-editor` (or CapCut) · Meta Ads Manager
**Master skill:** `campaign-director` (attach it alone if you can attach only one skill; it tells you when
to switch to the others)
**Inputs:** product, reference photos, brief (or client message), `templates/capstone-brief.md`

---

## Step 1: BRIEF
| Do | Skill / template | Output | Check |
|---|---|---|---|
| Decode the brief / client message | `brief-and-strategy` + `templates/creative-brief.md` | 1-page brief | KPI, audience, one message, mandatories all filled |
| Research audience, reviews, competitor ads (Meta Ad Library) | `brief-and-strategy` + `templates/audience-angle-matrix.md` | scored matrix, positioning line | Top 3 ideas chosen |
| Build or update the Brand Bible | `brand-bible-builder` + `templates/brand-bible.md` | Brand Bible + LOOK BLOCK | Exact label text and palette in it |

## Step 2: CONCEPT
| Do | Skill / template | Output | Check |
|---|---|---|---|
| Big idea | `brief-and-strategy` | 1-line idea | Fits audience + brand + proof |
| Hooks | `hook-and-script-writer` + `templates/hook-bank.md` | 30 → 5 hooks | Works on mute, product by 2 s |
| Script + storyboard | `hook-and-script-writer` + `templates/script-storyboard.md` | 15s/30s script + 6 frames with prompts | Timings add up |
| Shot list | `templates/shot-list.md` | all shots + continuity | Every shot has a start-frame name |

## Step 3: VISUALS
| Do | Workflow | Output | Check |
|---|---|---|---|
| Product images | **W01** | packshots, lifestyle, festive, e-com | `product-accuracy-checker` = SHIP |
| Label fixes | **W03** | corrected images | letter-perfect label |
| Brand model | **W02** | character sheet + CHARACTER BLOCK | same face in every frame |
| Storyboard start frames | **W05** step 3 | 6 frames side by side | Look like one shoot |

## Step 4: MOTION
| Do | Workflow | Output | Check |
|---|---|---|---|
| Video shots | **W04** | approved clips | product accurate in first/middle/last frame |
| Campaign film | **W05** | assembled film | one story, one look |
| UGC ad | **W06** | UGC video | feels native, disclosure handled |
| VO + music + SFX | **W07** | audio files | clear VO, licensed music |
| Hybrid shots (optional) | **W09** | real + AI blended | no visible jump |

## Step 5: EDIT
| Do | Skill | Output | Check |
|---|---|---|---|
| Edit with the 5 steps: Dump → Vibe → Beat → Layer → Sound | `vibe-editor` | 30s + 15s cuts | hook in 2 s, cut on beat |
| Captions, end cards | `vibe-captions-and-endcards` | captioned videos + end cards | works on mute, CTA clear |
| Director pass (max 3 notes) | `vibe-editor` | final cuts | you'd stop scrolling for it |
| All ratios + export | `vibe-editor` | 9:16, 4:5, 1:1 at Meta specs | safe zones, -14 LUFS, +faststart |

## Step 6: LAUNCH
| Do | Workflow / skill | Output | Check |
|---|---|---|---|
| 10 variations | **W08** + `meta-ad-variations` | named variation set | 1 variable per test group |
| Policy check | `ad-policy-check` + `templates/policy-checklist.md` | checklist ✅ | current Meta + ASCI checked |
| Campaign plan | `templates/campaign-plan.md` | structure, budget, win rule | tracking works |
| Launch + read results | Meta Ads Manager + `ad-performance-analyst` + `templates/test-log.md` | round-2 plan | decisions from real numbers |
| Case study | `case-study-and-pitch` + `templates/case-study.md` | portfolio piece | shows process, not just results |

## One-day sprint version (small campaign)
| Time | Step |
|---|---|
| 09:00–10:00 | Brief + Brand Bible + big idea |
| 10:00–11:00 | Hooks, script, storyboard, shot list |
| 11:00–13:00 | Product images + model + start frames (W01–W03) |
| 14:00–16:00 | Video shots (W04/W05) + UGC take (W06) |
| 16:00–17:00 | VO + music (W07) |
| 17:00–18:30 | Vibe edit, captions, end cards, ratios |
| 18:30–19:30 | Variations + policy check + campaign set-up (W08) |

## Final checklist (matches the capstone rubric)
- [ ] **Strategy:** clear audience, insight, one-line idea, test plan with win rule
- [ ] **Art direction:** looks shot, not generated
- [ ] **Product accuracy:** label perfect in every asset
- [ ] **Brand consistency:** one look, one model, one end card
- [ ] **Motion & sound:** smooth moves, clean mix
- [ ] **Meta readiness:** all ratios, safe zones, captions, CTA, names, policy check
