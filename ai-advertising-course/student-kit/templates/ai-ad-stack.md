**How to fill:** Pick one tool per job. Start with the free or cheapest option and upgrade only when it
blocks you (watermarks, low resolution, no commercial use, too few credits). Prices change often, so this
sheet has no prices: **check each tool's current plan page** and write today's price in your copy.

## Credit-saving rules
1. Make the image right first. Video from a bad start frame wastes credits.
2. Test prompts at low resolution or with fast/draft models, then make the final in high quality.
3. Generate 2–4 takes, not 10. Fix the prompt instead of rolling the dice.
4. Write every prompt with a skill first. A good prompt saves 5 bad generations.
5. Save every prompt that worked in your own prompt library.
