# How to prompt a vibe edit: credits

Every clip and object on screen is real footage or a real photograph. The crosshair lines,
light trails, gold tags, chat UI, prompt bar, cursor, spotlights and the "vibe editing"
wordmark are drawn as part of the design (style after the user's reference video 1).
