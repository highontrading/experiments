# T01B · Watch me edit this, just by talking: credits

Hook-test variant B of the T01 live demo. Same body as T01A and T01C (same voice take, same
raw clip, same four commands); only the first ~3 seconds differ. Design follows the user's
cinematic dark reference (crosshair lines, glowing tile, airy sans + glowing italic serif,
gold tags with light trails, white flash cuts, dark agent UI, light studio floor with a
tilted black bar and orange button, 3D cursor).
